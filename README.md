## Comandos
- **npm run dev** - Levanta la API en un server de desarrollo
- **npm test** - Corre test unitarios y de integración
- **npm run test:watch** - Corre vitest en modo watch
- **npm run test:coverage** - Reporte de cobertura
- **npm run test:ui** - Corre una interfaz gráfica para ver los tests

- **npm run build** - Hace el traspaso de ts a js
- **npm run start** - Levanta la API
